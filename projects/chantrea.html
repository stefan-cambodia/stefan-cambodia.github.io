The idea

One business, five languages, nothing hidden.

Chantrea Systems is Stefan, in Kampot: one person for websites, Android apps, AI, Windows and Linux servers and IT security. The site says so plainly, in the visitor’s language. Each language has its own address (/fr/, /en/, /km/, /ru/, /zh/), and the root page asks which one to open instead of guessing.

French is the source. The English, Khmer, Russian and Chinese texts were translated by Claude from the French, and a small script lists every translated text next to its French original so that native speakers can review it: required for Khmer, advised for Russian and Chinese. No text has been marked as reviewed yet.

Visitors are not followed: there is no cookie, no analytics and no third-party request, and the fonts are served by the site itself. The only JavaScript remembers the light or dark theme.

The pages

Ten pages in each language.

PageWhat it holds
HomeThe four services, HMS in brief, “one point of contact”, the four steps of working together marked by moon phases, who it is for, and a link to the work.
ServicesAn overview, then one page per service: development (multilingual websites, Android apps), artificial intelligence (start with one task, a person decides), infrastructure (Windows and Linux, virtualization with XCP-ng) and IT security, kept to a general text.
HMSThe hotel management software: its features in twelve groups, from bookings to reports, how it is installed, its languages and currencies, and screenshots of a demo hotel with made-up names and amounts.
WorkReal projects in two groups, products a client can be offered (HMS, Learn-kh) and proof of skills (Cambodia Rally, Angkor World Engine, Synth Rack, VSM Studio, the Android games), each with its actual status.
AboutWho is behind it and why “Chantrea”, moonlight in Khmer. The background and working languages are still to be written.
ContactButtons to write by e-mail, Telegram or WhatsApp, and what to say in a first message. Telegram and WhatsApp are not filled in yet.

A page to choose the language and a “page not found” in all five languages complete the set.

Highlights

Calm light, plain HTML.

A moonlit theme

The hero is night blue with a crescent moon, and the four steps are marked by moon phases. In the light theme the content is a pale lunar grey and the header and footer turn cream; in the dark theme everything is night. The device setting is followed by default, a button changes it, the choice is remembered, and the browser bar takes the header colour.

The logo

A penguin sitting in a crescent moon, drawn as SVG in the code. The crescent is cut out with a mask, so it stays transparent on any background, and its colours come from CSS variables: green on night, dark green on cream. Beside it, the logotype chantrea_ SYSTEMS ចន្ទ្រា. The favicon switches with the browser’s light or dark mode.

The Khmer name

The Khmer name in the logo is set in Kantumruy Pro, Light on the night header and Medium on the cream one; the Latin letters are in JetBrains Mono. The name is read from the Khmer text file, so it goes through the same native review as every other Khmer text.

Five scripts set properly

Khmer text is set in Noto Sans Khmer with taller lines for stacked vowels, Chinese uses the system’s Chinese fonts, and the language switcher shows each language in its own script. All web fonts are packaged with the site: no request goes to Google Fonts.

Works without JavaScript

The language switcher and the phone menu are plain HTML <details> elements, so they open without any script. The only scripts set the theme: one reads the saved choice before the page is drawn, the other runs the button.

Ready for search engines

Every page links to its versions in the other languages, with a canonical address and a sitemap that knows the languages. Structured data describes the business and each service, and the “page not found” is kept out of the index.

Edited without touching code

Every text sits in one file per language, with the same keys in all five. The address, contact details and legal notices are in one configuration file. A text still to be written shows on the site highlighted in yellow, so it cannot be forgotten.

Light images

The HMS screenshots are turned into AVIF and WebP in several sizes at build time and load only as they come near the screen. Each language opens on a screenshot in that language when one exists: the calendar in French, the dashboard in Khmer, the front desk in Chinese, the reports in Russian.

Le principe

Une entreprise, cinq langues, rien de caché.

Chantrea Systems, c’est Stefan, à Kampot : une seule personne pour les sites web, les applications Android, l’IA, les serveurs Windows et Linux et la sécurité informatique. Le site le dit simplement, dans la langue du visiteur. Chaque langue a sa propre adresse (/fr/, /en/, /km/, /ru/, /zh/), et la page racine demande laquelle ouvrir au lieu de deviner.

Le français est la langue source. Les textes anglais, khmers, russes et chinois ont été traduits par Claude depuis le français, et un petit script liste chaque texte traduit à côté de son original français pour la relecture par des locuteurs natifs : obligatoire pour le khmer, conseillée pour le russe et le chinois. Aucun texte n’est encore marqué comme relu.

Le visiteur n’est pas suivi : aucun cookie, aucune mesure d’audience, aucune requête vers un tiers, et les polices sont servies par le site lui-même. Le seul JavaScript retient le thème clair ou sombre.

Dix pages dans chaque langue.

Points forts

Lumière douce, HTML simple.

Un thème au clair de lune

Le haut de page est bleu nuit avec un croissant de lune, et les quatre étapes sont marquées par des phases de lune. En thème clair, le contenu est d’un gris lunaire pâle et l’en-tête comme le pied de page passent en crème ; en thème sombre, tout est de nuit. Le réglage de l’appareil est suivi par défaut, un bouton le change, le choix est retenu, et la barre du navigateur prend la couleur de l’en-tête.

Le logo

Un pingouin assis dans un croissant de lune, dessiné en SVG dans le code. Le croissant est découpé par un masque : il reste transparent sur n’importe quel fond, et ses couleurs viennent de variables CSS, vert sur la nuit, vert foncé sur le crème. À côté, le logotype chantrea_ SYSTEMS ចន្ទ្រា. Le favicon change avec le mode clair ou sombre du navigateur.

Le nom khmer

Le nom khmer du logo est composé en Kantumruy Pro, en graisse légère sur l’en-tête de nuit et moyenne sur l’en-tête crème ; les lettres latines sont en JetBrains Mono. Le nom est lu dans le fichier de textes khmers : il passe par la même relecture native que tous les autres textes khmers.

Cinq écritures bien composées

Le khmer est composé en Noto Sans Khmer, avec des lignes plus hautes pour les voyelles superposées, le chinois utilise les polices chinoises du système, et le sélecteur affiche chaque langue dans sa propre écriture. Toutes les polices web sont livrées avec le site : aucune requête vers Google Fonts.

Fonctionne sans JavaScript

Le sélecteur de langue et le menu du téléphone sont de simples éléments HTML <details> : ils s’ouvrent sans aucun script. Les seuls scripts concernent le thème : l’un lit le choix enregistré avant l’affichage de la page, l’autre fait marcher le bouton.

Prêt pour les moteurs de recherche

Chaque page renvoie vers ses versions dans les autres langues, avec une adresse canonique et un plan du site qui connaît les langues. Des données structurées décrivent l’entreprise et chaque service, et la page « introuvable » reste hors de l’index.

Modifiable sans toucher au code

Chaque texte se trouve dans un fichier par langue, avec les mêmes clés dans les cinq. L’adresse, les coordonnées et les mentions légales sont dans un seul fichier de configuration. Un texte encore à écrire s’affiche surligné en jaune sur le site : impossible de l’oublier.

Des images légères

Les captures de HMS sont converties en AVIF et WebP, en plusieurs tailles, au moment de la construction, et ne se chargent qu’à l’approche de l’écran. Chaque langue s’ouvre sur une capture dans cette langue quand elle existe : le calendrier en français, le tableau de bord en khmer, la réception en chinois, les rapports en russe.

Under the hood

How it is built.

FrameworkAstro 7 in static mode: nine page files and thirteen small components produce 52 HTML pages, ten per language plus the language choice and the “page not found”.
TextsOne JSON file per language in src/i18n/, with the same keys in all five, about 270 texts each. Adding a language means adding its file and switching it on in the configuration.
Configurationsite.config.mjs holds the site name, its address and base path, the contact details, the legal notices (left empty until the company is registered) and the list of languages.
StyleOne stylesheet of about 300 lines; the colours of both themes and of the logo are CSS variables.
FontsNoto Sans Khmer, Kantumruy Pro and JetBrains Mono from Fontsource, bundled with the site; system fonts for Latin, Cyrillic and Chinese text.
Reviewscripts/relecture.mjs writes docs/RELECTURE.md, every translated text beside its French original, with a status file to mark each one as reviewed.
PublishingWork happens on a site branch; merging it into main starts GitHub Actions, which builds with the Astro action and publishes to GitHub Pages.
Still openTelegram and WhatsApp, the background and working languages on the About page, the legal notices, the review of the translations, and a domain of its own, whose steps are written down in docs/DOMAINE.md.
Sous le capot

Comment c’est construit.

FrameworkAstro 7 en mode statique : neuf fichiers de pages et treize petits composants produisent 52 pages HTML, dix par langue, plus le choix de la langue et la page « introuvable ».
TextesUn fichier JSON par langue dans src/i18n/, avec les mêmes clés dans les cinq, environ 270 textes chacun. Ajouter une langue, c’est ajouter son fichier et l’activer dans la configuration.
Configurationsite.config.mjs contient le nom du site, son adresse et son chemin de base, les coordonnées, les mentions légales (vides tant que l’entreprise n’est pas immatriculée) et la liste des langues.
StyleUne feuille de style d’environ 300 lignes ; les couleurs des deux thèmes et du logo sont des variables CSS.
PolicesNoto Sans Khmer, Kantumruy Pro et JetBrains Mono depuis Fontsource, livrées avec le site ; les polices du système pour le latin, le cyrillique et le chinois.
Relecturescripts/relecture.mjs écrit docs/RELECTURE.md, chaque texte traduit à côté de son original français, avec un fichier d’état pour marquer chacun comme relu.
PublicationLe travail se fait sur une branche site ; sa fusion dans main lance GitHub Actions, qui construit le site avec l’action Astro et le publie sur GitHub Pages.
Reste à faireTelegram et WhatsApp, le parcours et les langues de travail de la page À propos, les mentions légales, la relecture des traductions, et un nom de domaine propre, dont la marche à suivre est écrite dans docs/DOMAINE.md.

  2. 18 Nov 2026
    The logo and a cream light theme

    The penguin sitting in a crescent moon becomes the logo, in the header, the footer, the language page, the “page not found” and the favicon, beside the logotype chantrea_ SYSTEMS ចន្ទ្រា. Its Khmer name is set in Kantumruy Pro and read from the Khmer text file, so it is reviewed like the other Khmer texts. In the light theme the header and footer turn cream with a light version of the logo, and the favicon follows the browser’s light or dark mode.

  3. 18 Nov 2026
    Screenshots of the demo hotel

    The HMS page gains ten screenshots from the hms repository, taken in a demo hotel with made-up data; each language opens on a screenshot in that language when there is one. The images are served in AVIF and WebP in several sizes, load only as needed and have captions and alt texts in the five languages. Full reports and the desktop app’s login screen were left out.

  4. 18 Nov 2026
    Four more languages, and their review

    The French texts are translated into English, Khmer, Russian and Chinese. A script lists every translated text beside its French original for native speakers to review, required for Khmer and advised for Russian and Chinese, with a status file to mark each one as reviewed.

  5. 18 Nov 2026
    The site, in French first

    The site starts as an Astro project with one configuration file and its texts in French: the home page with the light and dark theme, the language choice and a phone menu that needs no JavaScript, then one page per service, HMS, the work, About and Contact. GitHub Pages publishes it from main. The README explains how to edit a text, add a project and publish, and the steps for a domain of its own are written down.
