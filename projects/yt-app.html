TubeGuard

yt-app

A YouTube browser for Android, built on GeckoView — Firefox’s engine — so that it can run its own ad-blocking extension. One full-screen window and no address bar: it opens YouTube links, keeps the sound on with the screen off and shrinks into picture-in-picture, like a native app. A personal project: it goes against YouTube’s terms of service and is not distributed.

The idea

YouTube, and nothing around it.

On a phone, YouTube is either the official app or a tab in a browser. TubeGuard is a third way: a single full-screen window that loads the mobile site, m.youtube.com, with no address bar and no tabs, and handles the Android back button, links and sharing the way an app does. The Google account stays signed in from one launch to the next.

It exists to block ads, and that decides the engine. Android’s built-in WebView cannot run browser extensions, so it cannot block requests — injecting CSS or JavaScript into the page does nothing against the ads played before a video. GeckoView, the engine of Firefox for Android, runs WebExtensions, so TubeGuard ships with one of its own. The price is size: 195 MB for the arm64 APK, 152 MB of it for the Gecko engine alone.

It is a personal project, built from source and installed by hand on its author’s own phone. Blocking ads goes against YouTube’s terms of service, Google could in theory restrict an account used this way, and Play Store rules forbid apps that alter a third-party service — so it is not published anywhere. It uses neither YouTube’s name nor its logo. As its README points out, creators are paid by advertising; YouTube Premium is the way to watch without ads and still support them.

Highlights

Three layers against ads.

The built-in extension, ytblock, works at three levels: the network, the video player and the page.

Network filtering

A filter engine reads lists in the Adblock Plus format — a subset: domain anchors, wildcards, type and domain options, exceptions, cosmetic rules — and cancels matching requests before they leave the phone.

Lists that work offline

Two lists ship in the app: 62 rules aimed at YouTube and 127 taken from the core of EasyList, active from the first second. The full EasyList and a cosmetic list from the uBlock Origin project are downloaded on first launch, cached and refreshed every three days; that update can be switched off.

The player is told there are no ads

YouTube describes its ad breaks in the data it sends to the player, under keys such as adPlacements, playerAds and adSlots. A content script removes them before the player reads them, through Firefox’s own way of reaching into a page — the only one that gets past YouTube’s strict Content Security Policy.

A safety net

If a pre-roll or mid-roll starts anyway, it is spotted (the ad-showing class on the player), muted and jumped to its end, and the “Skip ad” button is clicked.

No flash of banners

A style sheet hides banners, promoted videos and overlays. It is injected before the page first draws, so they never flicker into view.

A list it must never block

On YouTube, ads and videos come through the same addresses (/youtubei/v1/player, googlevideo.com). A rule that is too broad does not remove the ad, it breaks playback. A fixed list of addresses that must always pass is checked before any rule.

Limits

An arms race YouTube can win.

The README is blunt about it. The script relies on the internal names YouTube uses today — JSON keys, CSS classes — and YouTube changes its player regularly, sometimes precisely to break this kind of blocking. When it does, the script has to be fixed by hand, by inspecting the page from desktop Firefox through remote debugging. YouTube also detects ad blockers and has shown warnings since 2023; and if it ever stitched ads into the video stream itself, as Twitch has done, neither filtering nor skipping would work.

The filter engine understands only a subset of the Adblock Plus syntax — none of uBlock Origin’s procedural filters, scriptlets or redirects — which matters little on YouTube, where the content script does most of the work. A second route, loading uBlock Origin itself as a bundled extension, is written but switched off: GeckoView refuses most of the permissions it asks for, and uBlock Origin’s code is not redistributed, so its folder ships empty.

Le principe

YouTube, et rien autour.

Sur un téléphone, YouTube, c’est soit l’application officielle, soit un onglet de navigateur. TubeGuard est une troisième voie : une seule fenêtre plein écran qui charge le site mobile, m.youtube.com, sans barre d’adresse ni onglets, et qui gère le bouton retour d’Android, les liens et le partage comme le ferait une application. Le compte Google reste connecté d’un lancement à l’autre.

Il existe pour bloquer les publicités, et c’est ce qui impose le moteur. La WebView intégrée à Android ne sait pas exécuter d’extensions de navigateur, donc pas bloquer de requêtes : injecter du CSS ou du JavaScript dans la page ne peut rien contre les pubs diffusées avant une vidéo. GeckoView, le moteur de Firefox pour Android, exécute les WebExtensions : TubeGuard embarque donc la sienne. Le prix à payer, c’est la taille : 195 Mo pour l’APK arm64, dont 152 Mo pour le seul moteur Gecko.

C’est un projet personnel, compilé depuis les sources et installé à la main sur le téléphone de son auteur. Bloquer les publicités contrevient aux conditions d’utilisation de YouTube, Google pourrait en théorie restreindre un compte utilisé de cette façon, et les règles du Play Store interdisent les applications qui altèrent un service tiers : il n’est donc publié nulle part. Il n’utilise ni le nom ni le logo de YouTube. Comme le rappelle son README, les créateurs sont rémunérés par la publicité ; YouTube Premium reste le moyen de regarder sans pub tout en les soutenant.

Points forts

Trois couches contre les pubs.

L’extension intégrée, ytblock, agit à trois niveaux : le réseau, le lecteur vidéo et la page.

Filtrage réseau

Un moteur de filtres lit des listes au format Adblock Plus — un sous-ensemble : ancrages de domaine, jokers, options de type et de domaine, exceptions, règles cosmétiques — et annule les requêtes concernées avant qu’elles ne quittent le téléphone.

Des listes qui marchent hors ligne

Deux listes sont livrées dans l’application : 62 règles visant YouTube et 127 tirées du noyau d’EasyList, actives dès la première seconde. L’EasyList complète et une liste cosmétique du projet uBlock Origin sont téléchargées au premier lancement, mises en cache et rafraîchies tous les trois jours ; cette mise à jour peut être désactivée.

Le lecteur croit qu’il n’y a pas de pub

YouTube décrit ses coupures publicitaires dans les données qu’il envoie au lecteur, sous des clés comme adPlacements, playerAds et adSlots. Un script de contenu les retire avant que le lecteur ne les lise, par la méthode propre à Firefox pour intervenir dans une page — la seule qui passe la politique de sécurité du contenu (CSP), très stricte, de YouTube.

Un filet de sécurité

Si une pré-roll ou une mid-roll démarre quand même, elle est repérée (classe ad-showing sur le lecteur), le son est coupé, la lecture saute à la fin du spot et le bouton « Passer l’annonce » est cliqué.

Pas de bandeaux qui clignotent

Une feuille de style masque bannières, vidéos sponsorisées et incrustations. Elle est injectée avant le premier affichage de la page : rien n’apparaît le temps d’être masqué.

Une liste à ne jamais bloquer

Sur YouTube, pubs et vidéos passent par les mêmes adresses (/youtubei/v1/player, googlevideo.com). Une règle trop large ne supprime pas la pub, elle casse la lecture. Une liste fixe d’adresses qui doivent toujours passer est vérifiée avant toute règle.

Limites

Une course que YouTube peut gagner.

Le README ne le cache pas. Le script s’appuie sur les noms internes qu’emploie YouTube aujourd’hui — clés JSON, classes CSS —, et YouTube modifie régulièrement son lecteur, parfois précisément pour casser ce genre de blocage. Quand cela arrive, il faut corriger le script à la main, en inspectant la page depuis Firefox sur ordinateur grâce au débogage à distance. YouTube détecte aussi les bloqueurs et affiche des avertissements depuis 2023 ; et s’il insérait un jour les pubs directement dans le flux vidéo, comme l’a fait Twitch, ni le filtrage ni le saut ne fonctionneraient plus.

Le moteur de filtres ne comprend qu’un sous-ensemble de la syntaxe Adblock Plus — ni les filtres procéduraux d’uBlock Origin, ni ses scriptlets, ni ses redirections —, ce qui compte peu sur YouTube, où le script de contenu fait l’essentiel du travail. Une seconde voie, charger uBlock Origin lui-même comme extension embarquée, est écrite mais désactivée : GeckoView refuse la plupart des permissions qu’il demande, et le code d’uBlock Origin n’est pas redistribué, si bien que son dossier est livré vide.

Under the hood

How it is built.

MainActivity.ktThe single full-screen window: immersive mode, back button, links, sharing, picture-in-picture. While audio plays in the background, it re-asserts every 3 seconds that the Gecko session is active; without that, GeckoView cut the sound after a few tens of seconds.
GeckoEngine.ktOne Gecko runtime and one session for the whole app, with the browser profile and the saved state of the current page.
PlaybackService.ktA foreground service with a wake lock and a MediaSession: the playback notification, lock-screen controls and headset buttons.
NativeBridge.kt · MediaBridge.ktThe channel between the app and the extension’s content script, and the state of the web player that the notification reflects.
ytblock/The extension (WebExtension, Manifest V2): network blocking in background.js and lib/filters.js, player hooks and ad skipping in content/ads.js, cosmetic rules in content/ads.css. To keep playing in the background or in picture-in-picture, the content script tells YouTube the page is always visible and focused, and ignores the player’s own calls to pause the main video.
BuildKotlin, GeckoView 154, Android Gradle Plugin 9.3, compile SDK 37.1, Android 8.0 or later (min SDK 26). One APK per architecture: 195 MB for arm64-v8a, 157 MB for armeabi-v7a.

Comment c’est construit.

MainActivity.ktLa fenêtre plein écran unique : mode immersif, bouton retour, liens, partage, picture-in-picture. Tant que l’audio joue en arrière-plan, elle réaffirme toutes les 3 secondes que la session Gecko est active ; sans cela, GeckoView coupait le son au bout de quelques dizaines de secondes.

ytblock/L’extension (WebExtension, Manifest V2) : blocage réseau dans background.js et lib/filters.js, interception du lecteur et saut des pubs dans content/ads.js, règles cosmétiques dans content/ads.css. Pour continuer à jouer en arrière-plan ou en vignette, le script de contenu fait croire à YouTube que la page est toujours visible et active, et ignore les appels du lecteur qui mettent la vidéo principale en pause.
